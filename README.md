
# Keepsake

An anonymous space for memories, confessions, reflection, and meaningful human connection.

## About

Keepsake is an experimental social platform built around emotional expression, personal reflection, and meaningful conversations.

## Current Status

Early prototype. The current version stores data locally in the browser and does not yet support real multi-user interaction.

## Built With

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in your browser.
